# 0023. 모델에게 보내는 근거의 시각 범위를 "부터 ~까지"로 풀어 쓴다

- 상태: 채택
- 날짜: 2026-11-05

## 배경

규칙 제3조는 "관생의 생활관내 출입시간은 06:00-23:00로 한다"이다. "기숙사 통금 몇 시까지야?"라고 물으면, 모델(exaone3.5:7.8b)이 범위의 앞 시각을 골라 "통금은 06:00까지"라고 자주 답했다.

- Jev가 이런 답을 숨기므로 학생에게 틀린 답이 보이지는 않았다. 대신 맞는 답도 보이지 않아 잘못 거절이 늘었다.
- 같은 질문을 같은 프롬프트로 물어도 답이 갈린다(temperature 0.2). 그래서 평가 1~2회로는 바뀐 것이 없어도 수치가 크게 흔들렸다(ADR 0022 측정).
- 같은 날 20번 물어보니 8번만 맞았다(12번 "06:00까지").

## 결정

모델에게 보내는 근거 글에서 시각 범위를 말로 풀어 쓴다(`answering.spell_time_ranges`).

- "06:00-23:00" → "06:00부터 23:00까지"
- "00:00-06:00까지" → "00:00부터 06:00까지" (까지가 겹치지 않게)
- "22:00 ~ 23:00" → "22:00부터 23:00까지"

저장된 원문, 화면, 시각 점검(ADR 0019)은 그대로 둔다. 챗봇과 관리자 답변 초안이 같은 프롬프트(`build_prompt`)를 쓰므로 둘 다 적용된다.

## 측정

**방법 비교**: Jev 없이 모델 답만 봤다. 통금은 20번, 다른 시각 질문(소등, 세탁기, 대청소)은 5번씩 물었다.

| | 통금 정답 | 소등·세탁기·대청소 |
|---|---|---|
| 지금 | 8 / 20 | 15 / 15 |
| 범위 풀어 쓰기 | **20 / 20** | 15 / 15 |
| 범위 풀어 쓰기 + "통금은 출입시간이 끝나는 시각" 뜻풀이 | 20 / 20 | 15 / 15 |

뜻풀이를 더해도 나아지는 것이 없었다. 통금에만 맞춘 장치라서 넣지 않았다.

**구현 후**
- 통금을 20번 물으니 20번 모두 23:00이었다.
- 챗봇 평가 2회를 돌렸다. 직전 main 결과는 `2026-11-05-chat-drop-5/6`, 이번 결과는 `2026-11-05-chat-ranges-1/2`다.

| | 직전 main | 이번 |
|---|---|---|
| 사실 정확도 | 0.87 / 0.83 | 0.89 / 0.93 |
| 잘못 거절 | 0.08 / 0.12 | 0.10 / 0.04 |
| 범위 밖 거절 | 1.00 / 1.00 | 1.00 / 1.00 |
| 통금 답이 보임 | 0 / 2 | 2 / 2 |
| 숨긴 답 | 4 / 6 | 5 / 2 |

## 남은 것

- "수요일 점심 메뉴"에 모델이 묻지 않은 대청소 시각을 틀리게 덧붙여 숨겨지는 일이 아직 있다. 질문의 "수요일"이 대청소 조항과 주제어로 겹쳐서, 시각 점검이 그 문장을 질문과 관계있는 말로 본다(ADR 0022의 `drop_offtopic_times`).
- 지각 벌점, 무단 외박 벌점은 모델이 벌점표의 항목 번호를 출처 번호처럼 인용하는 일이 가끔 있다.

## 추가 결정: 벌점표 번호 없애기, 요일·질문투 말은 주제어에서 빼기 (#94)

**벌점표**: 근거가 "12. 무단 외박, 호실 무단 변경: 7점"처럼 항목 번호를 달고 있었다. 모델이 이 번호를 출처 번호 [12]로 인용했다(출처는 5개뿐이라 검사에서 숨겨짐). 또 "17. 관내 흡연: 퇴관 / 18. 음주…"를 보고 "흡연은 벌점 18점"이라고도 답했다. 번호를 빼고 "- 무단 외박, 호실 무단 변경: 벌점 7점"으로 적는다. 저장된 결과에서 5보다 큰 번호를 인용한 답이 7개 있었다.

| Jev 없이 10번씩 | 지금 | 번호 없앰 |
|---|---|---|
| 지각 벌점 | 9 | 10 |
| 무단 외박 벌점 | 8 (2번은 [12] 인용) | 10 |
| 흡연 | 6 (4번은 "18점" 등) | 10 |
| 비밀번호 공유 벌점 | 10 | 10 |

**덧붙인 틀린 시각 문장 (ADR 0022 `drop_offtopic_times`)**: 질문과 문장의 주제어를 비교할 때 요일·때 표현("수요", "오늘", "매주")과 질문투의 말("있어", "하면", "무슨")을 뺀다.
- "수요일 점심"에 "수요일 대청소는 밤 10시부터 자정"(틀림)을 덧붙이면, "수요"가 겹쳐 같은 주제로 보고 답 전체를 숨겼다.
- "들어갈 수 있어?"와 "이용에 있어 … 자정까지"는 "있어"로 겹쳤다.
- 저장된 결과로 다시 나눠 봤다. 소등 "23:00"(4개)과 인원 점검(1개)은 그대로 숨긴다. 신입생·수요일·금요일의 덧붙인 문장만 뺀다.

**챗봇 평가 2회** (`2026-11-05-chat-penalty-1/2`, 벌점표 변경 뒤·질문투 말 빼기 전)

| | 직전 main (ranges-1/2) | 이번 |
|---|---|---|
| 사실 정확도 | 0.89 / 0.93 | 0.93 / 0.91 |
| 잘못 거절 | 0.10 / 0.04 | 0.04 / 0.06 |
| 범위 밖 거절 | 1.00 / 1.00 | 1.00 / 1.00 |
| 숨긴 답 | 5 / 2 | 2 / 4 |

- 지각·무단 외박 벌점과 수요일 점심은 2회 모두 숨겨지지 않았다.
- 2회차에 숨겨진 "신입생"은 위의 "있어" 겹침 때문이었고, 이 PR에서 함께 고쳤다.
- "벌점 많이 받으면"은 모델이 근거에 없는 조건("봉사 감면은 20점 미만일 때만")을 지어내 Jev가 숨겼다. 숨긴 판단이 맞다.
